# Nguyen Thanh Tu — Profile

This is my personal profile site. You can see it live at **https://shicukoe.github.io**.

It's a single page about my work as an AI engineer: my internship projects, my thesis, the skills I use, and
my certificates. I kept it deliberately simple. It's plain HTML and CSS, with no framework, no build step, and
no JavaScript, styled with a synthwave look I like: neon blue and pink, a retro sun, and a moving grid. It works
on phones too.

## Running it locally

There is nothing to install. Open `index.html` in a browser and you're looking at the site. If you prefer a
local server, `npx serve` in this folder works too.

All the content lives in `index.html`, all the styling is in `style.css`, and the photo is in `img/`.
